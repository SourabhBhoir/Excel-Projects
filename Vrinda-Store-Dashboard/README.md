# 📊 Vrinda Store Sales Report Dashboard (Excel)

## 📌 Project Overview

The **Vrinda Store Sales Report 2022 Dashboard** is an interactive data visualization project built in **Microsoft Excel**.
It analyzes sales performance, customer demographics, and platform-wise orders to help understand business trends and customer behavior.

The dashboard uses **pivot tables, slicers, and charts** to create a dynamic report that allows users to filter data by **month, sales channel, and gender**.

---

## 🎯 Objectives

* Analyze **monthly sales performance**
* Compare **orders vs sales trends**
* Identify **top selling states**
* Understand **customer demographics (age & gender)**
* Analyze **sales distribution across e-commerce platforms**

---

## 🛠 Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Data Visualization

---

## 📊 Dashboard Features

### 1️⃣ Orders vs Sales

* Shows comparison between **total orders and sales revenue**
* Helps identify trends and seasonal patterns

### 2️⃣ Sales by Gender

* Visualizes percentage of **men vs women customers**

### 3️⃣ Age Group Analysis

* Categorizes customers into:

  * Teenagers
  * Adults
  * Seniors

### 4️⃣ Sales Percentage by Month

* Displays **monthly contribution to total sales**

### 5️⃣ Top Products Selling States

* Shows states generating the **highest sales**

### 6️⃣ Top Sites According to Orders

Orders distributed across platforms such as:

* Amazon
* Flipkart
* Meesho
* Myntra
* Ajio
* Nalli
* Others

---

## 🎛 Interactive Filters

The dashboard includes slicers for:

* **Month**
* **Channel**
* **Gender**

These filters allow users to dynamically explore the data.

---

## 📈 Key Insights

* Majority of orders come from **women customers**
* **Adults** contribute the highest share of sales
* Platforms like **Amazon and Flipkart** generate the most orders
* Certain states dominate overall sales performance

4. Explore the charts to analyze trends.
