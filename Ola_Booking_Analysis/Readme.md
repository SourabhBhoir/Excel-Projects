# 🚖 OLA Booking Data Analysis using SQL

## 📌 Project Overview
This project analyzes OLA ride booking data using SQL. 
The goal is to extract meaningful business insights such as ride success rate, cancellations, revenue, customer behavior, and driver performance.

## 🛠 Tools Used
- MySQL
- SQL Queries
- Relational Database Concepts

## 📊 Business Questions Solved

1. Retrieve all successful bookings.
2. Calculate average ride distance for each vehicle type.
3. Count rides cancelled by customers.
4. Identify top 5 customers by total bookings.
5. Count driver cancellations due to personal/car issues.
6. Find maximum and minimum driver ratings for Prime Sedan.
7. Retrieve rides paid via UPI.
8. Calculate average customer rating per vehicle type.
9. Calculate total booking value of successful rides.
10. List incomplete rides with reasons.

## 📈 Key Insights
- Identified top customers contributing most bookings.
- Analyzed cancellation patterns.
- Compared vehicle performance using ratings and ride distance.
- Calculated total revenue from successful rides.

## 💡 Skills Demonstrated
- Aggregate Functions (SUM, AVG, COUNT, MAX, MIN)
- GROUP BY and ORDER BY
- Filtering using WHERE
- Business Insight Generation
- Data Analysis using SQL

## 📂 Database Used
Database Name: ola_booking_analysis  
Table Name: ola_booking
